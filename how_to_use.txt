QA Touch MCP Server - Prompt Guide

Use these prompts in Claude Desktop, Claude Code, Cursor, Windsurf, VS Code MCP clients, ChatGPT MCP clients, or any MCP-compatible AI assistant connected to this QA Touch MCP server.

Replace placeholders before use:
- PROJECT_KEY: QA Touch project key
- SECTION_KEY: QA Touch section/module key
- TEST_RUN_KEY: QA Touch test run key
- RESULT_KEY: QA Touch test run result key
- RELEASE_KEY: QA Touch release/milestone key
- DOCUMENT_KEY: QA Touch requirement document key
- TC-123: example test case code or search text
